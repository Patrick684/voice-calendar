======================================================
        语音日历工具 Demo 视频大纲（考核用）
======================================================

建议总时长：5-8 分钟

------------------------------------------------------
一、开场介绍（30秒）
------------------------------------------------------
- 项目名称：语音日历工具 (Voice Calendar)
- 定位：基于本地语音识别的智能日历管理桌面工具
- 核心卖点：语音驱动 + 完全离线 + 隐私保护
- 技术栈亮点：
  · Paraformer ASR（中文语音识别，准确率100%）
  · 意图分类模型（BERT微调，F1≥0.95）
  · 混合解析架构（规则引擎<10ms + LLM兜底）
  · Python 3.12 + CustomTkinter + SQLite

------------------------------------------------------
二、基础功能演示（2-3分钟）
------------------------------------------------------

【1. 语音添加事件】
- 操作：按住右Alt键说话，松开即执行
- 示例台词："明天下午三点团队会议"
- 展示重点：月历出现事件标记，事件卡片自动显示

【2. 多指令一句话】
- 示例台词："后天上午十点面试，下午三点开会，还有大后天上午九点跑步"
- 展示重点：一次语音创建3个事件，日期上下文自动继承

【3. 循环事件】
- 示例台词："每天早上九点晨会" / "每周六下午五点健身"
- 展示重点：月历上多天出现标记，自动生成RRULE循环规则

【4. 查询事件】
- 示例台词："今天有什么安排" / "看看这周的日程"
- 展示重点：弹出独立查询窗口，列出匹配事件

【5. 删除与修改事件】
- 示例台词："删掉明天的面试" / "把会议推迟半小时"
- 展示重点：事件消失（进入回收站）/ 时间变化

------------------------------------------------------
三、智能特性展示（1-2分钟）
------------------------------------------------------

【1. 优先级自动识别】
- 示例台词："紧急提交项目报告"
- 展示重点：事件卡片显示红色紧急标记 ❗

【2. 自动分类与颜色】
- 展示不同分类对应的颜色条：
  · 工作 → 蓝色
  · 健康 → 绿色
  · 学习 → 橙色
  · 生活 → 紫色
  · 娱乐 → 粉色
  · 社交 → 青色

【3. 中文时间智能理解】
- 展示对以下自然语言的正确解析：
  · "下周一" → 正确日期
  · "后天下午三点半" → 正确日期+时间
  · "每月15号" → 循环事件

【4. 同音纠错】
- 展示ASR输出经纠错后的正确结果
- 例："这株" → "这周"

------------------------------------------------------
四、GUI 交互演示（1-2分钟）
------------------------------------------------------

【1. 拖拽改期】
- 鼠标左键拖拽事件卡片到另一个日期格子
- 展示事件日期变更

【2. 时间拨盘微调】
- 点击事件卡片左侧颜色条
- 展示拨盘出现，拖拽调整时间（半小时精度）

【3. Ctrl+Z 撤销】
- 演示撤销上一步拖拽/时间调整操作

【4. 回收站】
- 展示已删除事件列表
- 演示恢复一个已删除事件

【5. 统计与成就系统】
- 展示热力图（事件密度可视化）
- 展示分类统计图表
- 展示成就徽章解锁

------------------------------------------------------
五、技术架构亮点（1分钟，口述+图示）
------------------------------------------------------

端到端流水线：
  录音 → Paraformer识别 → 同音纠错 → 标点恢复 → 指令解析 → 日历执行

混合解析策略：
  意图分类模型(BERT) → 规则引擎(正则+关键词) → LLM兜底(Ollama)

关键技术指标：
  · 语音识别准确率：中文100%（Paraformer）
  · 规则引擎解析延迟：<10ms
  · 意图分类F1-macro：≥0.95
  · 完全离线运行，零数据上传

录制建议
======================================================
1. 使用 OBS Studio 或 Win+G 录屏
2. 推荐「画外音 + 屏幕操作」方式（先录操作再配音更流畅）
3. 演示前先添加几条测试事件，让界面不那么空
4. 语音识别部分在安静环境录制，确保演示成功率
5. 可在视频开头加一张项目架构图（3秒停留）
6. 字幕建议：关键术语加中英双语标注
