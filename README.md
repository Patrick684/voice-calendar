# 语音日历工具 (Voice Calendar)

基于本地 Whisper 模型的桌面语音日历管理工具。通过语音指令添加、删除、查看日历事件，提升日程管理的效率与便捷性。

## 功能特性

### 语音交互
- **语音指令管理**: 说出"明天下午三点开会"等自然语言，自动创建日历事件
- **中文时间解析**: 支持"明天/后天/下周一/三点半/昨天/上周三"等中文时间表达式（含过去日期）
- **混合指令解析**: 规则引擎快速匹配 + 意图分类模型 + LLM 兜底理解复杂指令
- **多指令分割**: 一句话包含多条指令时自动拆分逐条执行
- **智能补全**: 不完整指令自动检测并补全（缺时间补明天14:00，缺标题用原始文本）
- **本地语音识别**: 基于 faster-whisper，无需联网，保护隐私
- **全局快捷键**: 按住右 Alt 键即可录音，松开自动识别并执行
- **智能后处理**: 同音纠错 + 标点恢复 + 繁简转换，提升指令识别准确率

### 事件管理
- **事件优先级**: 支持 0-3 级优先级（普通/重要/紧急/最高），语音关键词自动识别
- **事件自动分类**: 工作/健康/学习/生活/娱乐/社交/其他，基于标题关键词自动归类
- **循环事件**: 支持"每天/每周/每月/工作日"等循环规则，iCal RRULE 格式存储
- **软删除 + 回收站**: 删除事件可恢复，支持清空回收站
- **备份导出/导入**: JSON 格式全量备份，支持合并导入和覆盖导入

### 界面交互
- **日历视图**: 月历视图直观展示事件分布，事件日期标记圆点
- **拖拽排序**: 左键拖拽事件卡片到其他日期格子，自动更新日期（5px 移动阈值区分点击/拖拽）
- **时间拨盘**: 24h 水平标尺 + 半小时吸附，拖拽精调事件时间
- **排序切换**: 时间排序 / 优先级排序一键切换
- **分类颜色条**: 事件卡片左侧显示分类对应颜色
- **撤销支持**: Ctrl+Z 撤销拖拽和时间调整操作
- **事件提醒**: 后台定时扫描，分类差异化音效提醒，支持免打扰时段
- **个性化提醒**: 按事件分类播放不同提醒音效，可配置免打扰时段（支持跨日）

### 统计与成就
- **热力图日历**: 月度事件密度热力图，颜色深浅表示事件数量
- **分类统计**: 各分类完成率、进度条可视化
- **趋势分析**: 最近 14 天每日事件数量趋势图
- **连续打卡**: 计算连续有事件的天数
- **成就系统**: 10 个成就徽章（初次启程 → 效率大师），自动解锁 + 持久化存储

## 快速开始

### 环境要求

- Windows 10/11
- Python 3.10+ (推荐 3.12)
- 麦克风设备
- GPU (可选，NVIDIA CUDA 11.8+ 可加速 Whisper 推理)

### 安装

```bash
# 创建 Conda 环境
conda create -n voice_calendar python=3.12 -y
conda activate voice_calendar

# 安装 Python 依赖
pip install -r requirements.txt
```

### 运行

```bash
# Windows (需要管理员权限以监听全局快捷键)
python main.py
```

## 使用方式

### 语音指令

1. 启动后，主窗口显示日历视图
2. 按住 **右 Alt** 键开始录音
3. 说出日历指令，如:
   - "明天下午三点团队会议" → 添加事件
   - "每天上午九点晨会" → 添加循环事件
   - "重要的客户电话" → 自动标记高优先级
   - "删掉明天的面试" → 删除事件（进入回收站）
   - "今天有什么安排" → 查询事件
4. 松开按键，自动识别并执行

### 界面操作

| 操作 | 效果 |
|------|------|
| 点击月历日期 | 查看当日事件 |
| 左键点击事件卡片 | 打开编辑对话框 |
| 左键拖拽事件卡片到日期格子 | 移动事件到新日期 |
| 点击卡片左侧颜色条 | 选中事件，展开时间拨盘 |
| 拖拽拨盘滑块 | 调整事件时间（半小时精度） |
| 点击「+ 添加事件」 | 手动创建事件 |
| 点击「📈 统计」 | 查看热力图、分类统计、成就徽章 |
| 点击「⚙ 设置」 | 打开设置窗口 |
| Ctrl+Z | 撤销上次拖拽/时间调整 |
